# 驗收案例

這裡的案例用於檢查規則是否正確套用，不是供全域搜替換的禁字表。

| 輸入或情境 | 期望結果 | 要檢查的重點 |
|---|---|---|
| 使用服務器儲存數據。 | 使用伺服器儲存資料。 | 常見技術詞的標準譯法。 |
| 檢查項目並查看檢查結果。 | 保留原句。 | 「項目」在此是條目，不改成專案。 |
| 請到餐廳菜單選擇餐點。 | 保留「菜單」。 | 餐廳菜單不是軟體選單。 |
| 此食品的保存期限為三個月。 | 保留「保存」。 | 食品保存不是儲存檔案。 |
| 請在系統設置中修改設定。 | 依語境改為「設定」。 | 名詞性設定與動詞「設置」不同。 |
| 將 default value 設為 0。 | 將預設值設為 `0`。 | 技術文案使用繁體中文，數字與程式保持原格式。 |
| 請更新 README.md 中的中文安裝說明。 | 修改中文文字；檔名、Markdown、指令、網址與程式碼不變。 | 受保護內容與可編輯自然語言要分離。 |
| 文件提到「系統發生異常，請重新啟動」。 | 引文保留原樣。 | 引文不被改寫；必要時另列建議用語。 |
| 部署 3 台伺服器，頻寬為 10Gbps，並啟用 CDN. | 部署 3 台伺服器，頻寬為 10 Gbps，並啟用 CDN。 | 數字與單位空格、全形標點、英文句點。 |
| 設定(API)完成！ | 設定（API）完成。 | 全形標點與括號。 |
| 請使用 微信 與 支付寶。 | 請使用微信與支付寶。 | 專有名詞保留，中文連接處不多加空格。 |
| 尚未驗證此功能。 | 尚未驗證此功能。 | 否定與不確定性不可被潤飾掉。 |
| 請到 台鐵 官網查詢列車資訊。 | 請到台鐵官網查詢列車資訊。 | 機構名稱保留，中文兩側不多加空格。 |

驗收時同時確認：沒有新增事實、沒有改變指令行為、沒有破壞 Markdown，且輸出使用自然、直接的說法，而非機械式詞表重組。
