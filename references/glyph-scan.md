# 字形與標點自查

交件前必跑的輔助層檢查。只處理字形與標點；通過不代表用語或自然度合格，核心檢查是 SKILL.md 工作流程第 2、3、6 步。

## 簡體混入掃描

所有繁體中文輸出都要掃，短回覆也不例外——篇幅短不代表字形安全，一句話的回覆照樣掃。對整段輸出跑單字字元掃描，字元類：

```
[内经么转连负载户检设网启请录询运队际组织级给时个这们说为还进与发对条着装东别并谁证实应据线写层问关读验复让数备编属图试报论务页显继续举状盖后扫]
```

- 字元類只列「只以簡體形式出現」的常見字形，缺一個就會漏；命中新字形時才擴充。`何`、`行`、`作`、`者`、`定`、`西` 這類在正常繁體詞（任何、執行、工作、兩者、設定）裡就會出現，加進去讓掃描全是誤命中、反而漏掉真的。
- 異體或同形字形命中後依語境判斷，不得全域替換：`着`（aspect 助詞寫「著」）、`装`（衣物寫「裝」）、`东`、`后`（時間與前後端一律寫「後」，「后」只保留於「皇后」這類詞；「后端」是實際輸出裡出現過 5 次的真實誤用）。`别`、`并` 在繁體輸出一律寫「別」「並／併」。
- 詞表是詞級檢查，抓不到混入的單字；這就是為什麼要另外跑字元級。
- 可用 `rg`、編輯器搜尋或環境提供的搜尋工具；未提供工具時逐段檢查，不假稱執行過掃描。

```bash
rg -n '[内经么转连负载户检设网启请录询运队际组织级给时个这们说为还进与发对条着装东别并谁证实应据线写层问关读验复让数备编属图试报论务页显继续举状盖后扫]' -- ./output.md
```

`rg` 結束碼 0 有命中、1 無命中、2 搜尋錯誤；結果都是待複核線索，不是自動修改指令，也不是合格證明。

## 半形標點

對中文語境掃 `,.;:!?`——實際紀錄裡最高頻的排版錯誤是快速技術條列混半形逗號與冒號。受保護內容（程式碼、URL、完整英文句、引用原文）內的半形標點保留。

## 解讀結果

命中只代表需要複核，**零命中不代表合格**。
