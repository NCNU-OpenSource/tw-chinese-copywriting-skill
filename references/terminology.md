# 用語選擇

表格提供候選譯法，不授權機械式全域替換。使用「建議用語」前必須確認整句詞義符合該行；「保留原詞或依語境處理」代表詞表不提供可直接套用的通用替換，需保留原詞，或改寫不受詞表限制的自然說法。

❌ = 禁用（簡體或「繁體寫的大陸用語」都算）；✅ = 臺灣用語。情境另有標準譯法時以標準為準。

## IT／技術

| 常見寫法 | 建議用語 | 適用語境與例外 |
|---|---|---|
| 服务/伺服器 | 伺服器 | 系統、主機、服務角色皆適用；「服務業」「公共服務」等既有中文語意不強行改名。 |
| 软件／硬件 | 軟體／硬體 | 只用於電腦或電子系統；一般「軟實力」「硬體設備」依上下文保留。 |
| 数据库 | 資料庫 | 資料儲存系統。 |
| 代码 | 程式碼 | 原始碼、範例、錯誤訊息中的 code。 |
| 计算机 | 電腦 | 指裝置時。 |
| 内存 | 記憶體 | 電腦記憶體。 |

| 视频／音频 | 影片／音訊 | 「視頻通話」改「視訊」；媒體檔案與影音內容依媒介選擇。 |
| 信息 | 資訊、消息、資料 | 視原意選擇；「訊息」可能指 message，「資訊」指 information。 |
| 搜索 | 搜尋 | 一般搜尋功能；「搜查票」「搜索隊」等既有法律或機構用法保留。 |
| 用户 | 使用者 | 一般使用者、帳號持有者；服務業的「客戶」不因此改名。 |

| 默认 | 預設 | 形容預設值或預設行為時使用；「我默認了他的說法」不是預設。 |

## 不轉換（例外）

- 產品／平台專有名詞：微信、支付寶、淘寶、抖音、小紅書、Bilibili（照原名；提到國際版才用 TikTok）
- 大陸機構、公司、地名專名（照原名）
- 程式碼、指令、檔名、路徑、API／欄位名、設定鍵值
- 引文原文（保留引文中的原始用語，必要時括注）
- 通用英文技術詞照英文（GitHub、Kubernetes、API）

## 詞義優先

- 原文已有詞不一定是錯詞。不得僅因出現在左欄就強制替換。
- 先確認原句想表達的對象、動作與程度，再選擇慣用語；沒有自然對應時保留原文，不製造生硬譯法。
- 若同一字在左欄出現多次，逐行比較例外欄，避免把不同詞義混為一詞。

## 輔助搜尋

```bash
rg -n '服务|软件|硬件|数据库|代码|内存|硬盘|视频|音频|信息|搜索|用户|默认|加载|进程|线程|集群|镜像|域名|界面|菜单|设置|文档|文件|文件夹|项目|反馈|教程|打印|粘贴|拖拽|窗口|插件|缓存|带宽|端口|应用程序|网盘|快递|卫生间|培训|私信|点赞' -- ./output.md
```

```bash
rg -n '[内经么转连负载户检设网启请录询运队际组织级给时个这们说为还进与发对条着装东别并谁证实应据线写层问关读验复让数备编属图试报论务页显继续举状盖后扫]' -- ./output.md
```

`rg` 結束碼 0 代表有命中，1 代表沒有命中，2 代表搜尋錯誤；這些結果都是待複核線索，不是自動修改指令，也不是合格證明。沒有可用搜尋工具時，逐段檢查「簡體字形」與「繁體寫成的大陸用語」，不聲稱執行過掃描。第二個字元類只含簡體字形單字（詞表是詞級檢查，抓不到混入的單字），適合長篇中文產出的草稿自查；其中部分字在繁體另有用途（如「里」），命中後仍依語境判斷。
